# Owner report

Write it in the owner's language, short, plain words, no jargon. Four parts, in this order:

1. **What changed:** the new layout in one short list (his project's folder names), what moved, what was merged.
2. **Results:** baseline compare (`BASELINE MATCH` or what differs and why), tests, lint, the fresh-agent proofs.
3. **His decisions:** each open question, one line, with the default if he does not answer (also written into the
   project's status file).
4. **Cost:** weighted tokens for this run against the estimate announced in Phase 0.

End with the one thing he must do now, if any (for example: open `/hooks` once so new hooks load; approve a push).
